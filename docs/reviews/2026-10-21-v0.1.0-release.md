# v0.1.0 release acceptance

## Request and scope — 2026-10-21

The maintainer authorized a final team review, a `v0.1.0` tag and formal GitHub Release. The release must include an installable `.skill` archive, checksums and release notes. Existing user projects and running review pages must remain intact.

Review baseline: `633486c8b00866be4349d4b5fb26454bc9522633`. The first-release audit also covers the complete tracked snapshot and the earlier implementation range beginning at `e20b16f`. Requirements and standards come from `SKILL.md`, `CONTRIBUTING.md`, `docs/verification.md` and the product-quality and lighting acceptance records in this directory. Standards and Spec are reviewed independently.

## Confirmed release decisions

- Keep the five-view browser workflow and the accepted image-gen and lighting showcase.
- Publish the portable skill only; exclude source projects, generated reviews, environments, local sessions and caches.
- Distinguish host installation checks from live agent execution and macOS execution from metadata-based platform compatibility checks.
- Preserve public attribution and scan reachable Git history and packaged files for private identifiers.
- Tag the verified source commit; publish a normal, non-prerelease GitHub Release.

## Review findings and implementation

1. **Existing output could be deleted or overwritten.** The advanced project helper removed existing model files before checking ownership. Follow-up review found the same risk in review, demo, native and rendering helpers. Output producers now verify ownership, checksums, expected contents and source/output separation before mutation. Unknown, modified or symlinked files are rejected. Rendering routes without a manifest require a fresh target. Regression tests preserve sentinel files and exercise legitimate rebuilds, including changed drawing sets.
2. **Warm installations could include generated work.** The installer now excludes `output/`, `outputs/` and `.viewer-session.json` at every depth. Setup examples direct generated work outside the installed skill. A copied, previously used skill is checked for all four host destinations.
3. **The development dependency audit found high-severity Vite advisories.** Vite is pinned to 6.4.4. A fresh dependency installation, production build and complete npm audit are required from the final snapshot.

The accepted frontend composition and model geometry are unchanged by these release fixes. Active frontend builds are retained while verification uses isolated build directories.

## Practical limits

The synthetic drawing package is a coordination draft, not an approved construction issue. Image-gen output is a visual simulation; model and drawing evidence retain dimensional authority. Interactive lights are qualitative previews, not photometric calculations. macOS is the executed platform. Windows/Linux dependency metadata does not establish a live end-to-end test. Live Claude Code generation remains unverified because the earlier host test failed authentication before model execution; installation is verified separately.
