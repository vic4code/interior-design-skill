[Actual shared base](base.jpg). Spatial fixture S01 preserves room boundaries, opening positions and nominal furniture footprints across the study; style-specific geometry/finish examples and image simulations are alternative design representations. Generated upholstery, furniture edges, props and surface details may differ from the model. Direct visual comparison is not pixel registration, product verification or dimensional certification.

The built-in image tool did not expose a model identifier or per-image price. Provenance records actual prompts, base/result hashes and review findings without inventing those fields. The same derivatives and original geometry GLBs ship in `assets/review-demo` for a portable four-style demo. No private project material is included.
