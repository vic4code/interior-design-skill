# 需求 → 草模 → 材質光線 → 高清圖

「幫我做漂亮的室內設計」會讓模型自行猜測尺寸、家具與風格。先給限制，再討論畫面，結果更容易修改。

## 可直接貼給 agent 的起手式

> 請使用 interior-design skill。我想把心中的空間轉成高清渲染與能和設計師、工程師溝通的尺寸圖。先幫我整理需求和未確認尺寸，不要把示意值當成實測。免費本機流程，不使用付費 API。我的房間約 6000×4800 mm、淨高 2800 mm，南側入口、北側大窗；希望溫暖橡木、亞麻、暖白，白天可以工作，晚上安靜閱讀。先做草模確認動線，再逐輪調整材質與光線。請說明目前工具做不到的部分。

## 分輪溝通

1. **風格輪**：參考圖中喜歡的是配色、材質、家具輪廓，還是光線？寫出三項保留、三項避免。
2. **配置輪**：桌子靠窗、沙發長度、收納量、現有物件是否保留？先核對 mm 尺寸。
3. **材質輪**：橡木深淺、布料顏色、牆面反射、五金色調。v0.1 只有程序材質與示意家具，不假稱有產品細節。
4. **光線輪**：日照方向、時間感、陰影柔硬、曝光。光線與相機目前須修改生成腳本或在 Blender 做明確標示的展示版本。
5. **出圖輪**：先確認草模與構圖，再提高取樣與解析度。大圖不能補救錯誤比例。
6. **溝通輪**：給設計師看風格、配置與參考圖；給工程師看尺寸、名義門窗、材料意向和問題清單。由對應專業補齊施工做法。

## 更有效的修圖回饋

- 弱：「不夠高級。」
- 具體：「地板偏黃，調成淺自然橡木；沙發改低飽和米灰；不要改動門窗尺寸。」
- 弱：「再像照片一點。」
- 具體：「保留配置，改柔和側光、增加材質細節、選真實家具模型；先確認素材授權及是否免費。」
