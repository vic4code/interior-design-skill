# Reusable interior design methods

Apply these patterns when developing a model, browser review and coordination package together.

1. Design daily actions before appearance: equipment and cables, robot service, suitcase retrieval, chair and door travel.
2. Preserve a detailed Cycles scene and make lightweight browser derivatives.
3. Use stable IDs in native objects, drawings and furniture schedules.
4. Expose decisions through operation controls and named room/detail cameras.
5. Freeze the latest evaluated browser assembly when browser changes supersede the native model.
6. Produce base Blender renders and separate optional AI completion simulations. Keep the prompt and source relationship.
7. Distinguish geometry checks, offline rendering, actual browser checks and unverified site conditions.
8. Convert hard-coded coordinates, dates and paths into configuration. Publish synthetic examples and redistributable assets only.

The starter uses original procedural boxes to prove the shared-data path. Detailed product models and finished interior presentations require additional modeling and licensed assets.
