# Develop a professional drawing package

A professional-looking sheet is only useful when its dimensions, specifications and details resolve what the recipient needs to build. Set the drawing register for the actual project and track incomplete technical evidence instead of filling gaps with invented details.

For professional, quotation or contractor-facing requests, use [contractor-coordination.md](contractor-coordination.md) for the required record fields, trade interfaces and issue gates. This reference covers drawing content and graphical checks; the coordination reference governs package completeness.

## Scope the sheet register

| Discipline / sheet | Required content where applicable |
| --- | --- |
| Cover, register and revisions | Project/revision, purpose, sheet index, legends, units, datum, sources, assumptions and responsibility matrix |
| Existing/demolition/proposed plans | Structure and changes, wall thicknesses, opening tags, levels, overall and chained setting-out dimensions |
| Furniture and equipment | Real product envelopes, instance IDs, placement dimensions, use/maintenance envelopes and specification status |
| Reflected ceiling / lighting | Heights and soffits, fixture IDs, control intent, beam and access coordination, selected fixture specifications |
| Power/data and wet services | Existing versus proposed points/routes, mounting heights and equipment interfaces; trade design for capacities, circuits, sizes and protections |
| Interior elevations | Wall faces, openings, cabinetry, material extents, heights, datums and detail references |
| Joinery plans/elevations/sections | Overall, internal clear and component dimensions; panel build-up, gaps, door/drawer operation, service access, hardware and fixing questions |
| Details and schedules | Enlarged joints/interfaces, finish and hardware references, door/window/furniture/fixture schedules and issue register |

Select only relevant sheets, but identify missing sheets required for the requested purpose. Coordinate all disciplines against the same revision.

## Dimension and specify what matters

Use an explicit hierarchy: overall dimensions, chained setting-out dimensions, opening/component sizes and critical clear dimensions. Close dimension chains and check them against geometry. Avoid duplicate dimensions that can diverge. State the measurement basis and reference face.

For a cabinet, close width, depth and height stacks. Account for face thickness, rear panels, edge gaps, plinth, top, shelves and dividers. Separate external size, usable clear opening and selected equipment installation envelope. Show section location and viewing direction on the corresponding plan/elevation.

Use material/finish codes linked to specifications. Record core material, thickness, finish/sample status, edge treatment, relevant tolerance source and hardware model. Drilling patterns, hinge cups, anchor embedment and load capacity depend on actual products/substrates; leave them as explicit selection/review items until evidenced.

Show installation, service and human access. A door-swing sketch establishes design intent, not verified finished clear width or accessibility compliance. A proposed electrical symbol does not establish circuit design. Include source equipment instructions when selected.

## Make sheets readable

Use appropriate sheet sizes and scales; include a calibration bar where print scaling matters. Give cut elements, visible outlines, hidden lines, projections and dimensions distinct weights/styles. Keep text legible at actual print size, route leaders without crossing labels and give sections/detail references consistent IDs. Add units, revision, sheet title/number and issue status to every sheet.

Inspect rendered PDFs and SVGs, not only source code. Check cropping, text collisions, dimension closure, section-reference targets and the relationship to the native model. Verify the actual export units and CAD layer/line behavior before calling CAD files usable.

## Issue with evidence

Construction/fabrication issue status follows the available site survey, selected products, technical coordination and review responsibilities. Do not manufacture an approval signature or hide missing details behind attractive graphics. An advanced coordination sample can demonstrate professional drawing structure and detailed design dimensions while still recording the unresolved site and hardware items.

The bundled drawing study includes detailed plan/elevation, proposed services, cabinetry sections and schedules for an original fictional room. Its assumed dimensions are suitable for demonstrating the workflow; real project issue status must be decided from real project evidence.
